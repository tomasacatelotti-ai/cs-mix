# cs_audio

Motor de audio de CS Mix: dos decks, crossfader, transiciones (Fade, Reverse,
Brake, Corte), EQ de 5 bandas, salida principal + pre-escucha con retardo y
análisis de BPM / intro / forma de onda. Usa [miniaudio](https://miniaud.io)
(`src/miniaudio.h`, licencia en `src/MINIAUDIO_LICENSE`).
